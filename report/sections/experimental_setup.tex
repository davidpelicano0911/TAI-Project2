\section{Experimental Setup}
\label{sec:setup}

\subsection{Dataset}
The benchmark corpus consists of 8 raw astronomical images, each a
$1500\times1500$ raster of unsigned 16-bit big-endian pixels (4.5\,MB per
file). The images were acquired by different ground-based telescopes (VLT,
TJO, GTC, INT, JKT, LCO, WHT) and span a variety of noise levels, bias
pedestals, and spatial structures, including stellar fields and blank-sky
frames.

\subsection{Reference Compressors}
We compare against the generic tools most commonly used for scientific data:
\texttt{gzip} (levels 1, 6, 9), \texttt{bzip2} (levels 1, 9),
\texttt{xz} (levels 1, 6, 9), and \texttt{zstd} (levels 1, 3, 9, 19).
All are run without any pre-processing; the raw byte stream is passed directly.
Among the repository-specific codecs we also include \texttt{prism} and
\texttt{helix} for context.

\subsection{Evaluation Protocol}
The primary metric is bits per byte:
\[
  \text{bpp} = \frac{8 \times \text{compressed bytes}}{\text{original bytes}}.
\]
Timing (compress and decompress, wall-clock) is measured as a single run on a
single machine. Losslessness is verified by a byte-exact comparison of the
decompressed output with the original input file.
All compressors run on the same machine; the benchmark binary launches each
tool as a subprocess and records its elapsed time.
